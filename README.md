# Railway Reservation Management System

## Overview
A console-based Railway Reservation System developed using Core Java.

## Features
- User Registration
- User Login
- View Trains
- Search Train
- Book Ticket
- View Tickets

## Technologies Used
- Java
- OOP
- Collections Framework
- Exception Handling
